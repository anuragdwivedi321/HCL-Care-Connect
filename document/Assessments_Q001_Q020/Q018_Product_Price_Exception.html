Architect a Clinical Formulary Pricing Validation & Custom Exception subsystem in CareConnect EHR: 1. Healthcare Compliance Context: - Medication and medical device prices must adhere to government price caps (e.g., DPCO/CMS fee schedules) and cannot be negative, zero, or exceed statutory ceiling rates. 2. Custom Exception Architecture: - Create 'InvalidPharmaceuticalPricingException' extending RuntimeException with fields: errorCode, medicationId, attemptedPrice, statutoryCeilingPrice, and timestamp. 3. Validation Pipeline: - If attemptedPrice <= 0 -> throw InvalidPharmaceuticalPricingException('ERR-PRICE-ZERO-NEGATIVE', 'Medication price must be greater than zero.'). - If attemptedPrice > statutoryCeiling -> throw InvalidPharmaceuticalPricingException('ERR-PRICE-CEILING-BREACH', 'Price exceeds CMS ceiling cap.'). 4. Spring Integration: - Map exception in @RestControllerAdvice to RFC 7807 ProblemDetail with HTTP 422 Unprocessable Entity. 5. Unit Testing: - Assert custom exception thrown on negative prices and statutory cap breaches with correct error codes.
Enterprise Engineering & Project Alignment: Transforms a basic custom exception into an enterprise pharmaceutical regulatory pricing validator mapped to RFC-7807 REST responses.

"spring boot microservices bnao eureka aur api gateway ke sath"
Problem & Limitations: Vague Architecture: Lacks service boundary definitions, inter-service JWT propagation, and healthcare fault-tolerance patterns.
✓ AFTER : CARECONNECT EHR HEALTHCARE CONTEXT PROMPT
Architect an enterprise Healthcare Microservices Architecture for CareConnect EHR: 1. Service Domain Decomposition: - 'Auth-Service': Stateless JWT issuance, role management, and Spring Security. - 'Patient-Service': Enterprise Master Patient Index (EMPI) and demographics. - 'Pharmacy-Service': Prescription management and real-time Drug-Drug Interaction (DDI) engine. 2. Service Registry & API Gateway: - Spring Cloud Gateway: Central routing hub terminating TLS, authenticating JWT tokens, and propagating verified 'X-User-Role' headers downstream. - Eureka Discovery Server: Dynamic service registration and client-side load balancing. 3. Inter-Service Communication & Resilience: - OpenFeign client with Resilience4j Circuit Breaker: When Pharmacy-Service is unreachable, gracefully fall back to cached interaction safety rules. 4. Distributed Tracing: - Micrometer Tracing with Zipkin for end-to-end request latency observability across clinical microservices.
Enterprise Engineering & Project Alignment: Decomposes monolithic EHR into bounded healthcare microservices (Auth, Patient, Pharmacy) with Spring Cloud Gateway and Resilience4j.

Problem & Limitations: Generic CRUD Form: Misses LOINC diagnostic medical test catalogs, priority dropdowns (STAT/ROUTINE), and clinical validation rules.
✓ AFTER : CARECONNECT EHR HEALTHCARE CONTEXT PROMPT
Architect a Computerized Physician Order Entry (CPOE) Diagnostic Lab Requisition Form using Angular 17 Reactive Forms: 1. Clinical Context: - Physicians select and order diagnostic laboratory procedures (CBC, Lipid Panel, Metabolic Panel) with clinical priority triage. 2. Form Structure (FormBuilder): - patientMrn: ['', [Validators.required, Validators.pattern(/^MRN-\d{4}-\d{4}$/)]] - testType: ['LABORATORY', Validators.required] - loincCode: ['', Validators.required] (e.g., '58410-2' for Complete Blood Count) - priority: ['ROUTINE', Validators.required] (ROUTINE, URGENT, STAT) - clinicalIndication: ['', [Validators.required, Validators.minLength(10)]] 3. Dynamic Validation & Pre-Submission Guard: - If priority is 'STAT', require mandatory justification in clinicalIndication. - Show inline validation errors using accessible form-control states (is-invalid, ng-touched). 4. Submission Handler: - On valid submit, dispatch OrderDto to OrderService and trigger toast notification with order tracking number.
Enterprise Engineering & Project Alignment: Adapts a generic product form into an authentic CPOE diagnostic lab requisition form with LOINC codes and STAT triage validation.

Develop an enterprise Client-Side Validation Utility in JavaScript (ES6+) for CareConnect EHR registration: 1. Clinical Field Requirements: - Patient MRN: Must not be blank, must match exact 13-character pattern 'MRN-YYYY-XXXX', and reject leading/trailing whitespace. - Emergency Contact Phone: Must not be blank, minimum 10 digits after stripping non-numeric punctuation, adhering to ITU E.164. 2. Validation Functions: - validateMRN(mrnString): Trims whitespace, checks length == 13, and validates regex /^MRN-\d{4}-\d{4}$/. - validatePhone(phoneString): Normalizes string, checks cleaned digits length >= 10. 3. User Experience & Error Objects: - Return structured validation result: { isValid: boolean, field: string, errorMessage: string }. - Highlight invalid inputs in red with inline accessibility error descriptions (aria-invalid='true').
Enterprise Engineering & Project Alignment: Replaces generic string emptiness checks with exact MRN format matching, whitespace sanitization, and accessible error objects.
